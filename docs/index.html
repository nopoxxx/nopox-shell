~/docs/about

nopox-shell

Оболочка рабочего стола для композитора niri на Quickshell, целиком в стиле терминала: панель — строка shell-приглашения, меню — fzf, настройки — menuconfig, уведомления — строки лога, блокировка — getty. Палитра Gruvbox dark hard, шрифт Terminess (Terminus). Для Arch Linux и производных.

nopox@nopox-os ~/ws/{1,[2]} [1] ❯ kitty # ~/projects [‹ 󰙯 󰓓] · cpu ▂▃▅▇ 4% · mem 1.7G · vol 40% · upd 2 · log 0 · ru · 21:58
  • панель из 17 модулей по зонам left / center / right, TUI-попапы по клику;
  • меню Mod+D для действий: программы, обои, пакеты pacman/AUR, питание;
  • настройки Mod+S в стиле menuconfig с поиском — без правки конфигов руками;
  • окна мониторов, биндов и обоев (wallhaven.cc);
  • темы GTK и Qt в той же палитре, с тем же акцентом и шрифтом;
  • блокировка и greeter как getty, уведомления как лог, обновление shell одним кликом.
~/docs/install/

Установка

Arch Linux и производные (CachyOS, EndeavourOS, …), от обычного пользователя:

❯ bash <(curl -fsSL https://raw.githubusercontent.com/nopoxxx/nopox-shell/main/install.sh)

Установщик сначала задаёт вопросы, показывает итог и только потом ставит:

выборварианты
терминалkitty, alacritty, ghostty, foot — конфиг в Gruvbox + Terminess, Mod+Return
оболочкаzsh (подсказки и подсветка), fish, bash — приглашение как панель: user@host ~/путь ❯, красный ❯ после ошибки
браузерHelium, Firefox, Zen, Chromium, Brave, Vivaldi — станет браузером по умолчанию, Mod+Shift+B
файлыThunar, Nautilus, Dolphin, Nemo или yazi в терминале, Mod+E
программыпо группам: медиа, общение, графика, работа и код, игры, утилиты
Discordкак есть, с Vencord, с BetterDiscord или Vesktop вместо него

Дальше — пакеты (программы через paru: репозитории или AUR), клон shell в ~/.config/quickshell, конфиг niri (или два include к вашему) и, по желанию, greeter. Всё, что заменяется, остаётся рядом как *.bak-<дата>.

флаги

флагчто делает
--yesбез вопросов, всё по умолчанию; pacman и paru получают --noconfirm
--terminal --shell --browser --filesвыбор без вопроса, например --terminal foot
--apps mpv,discord,steamпрограммы (none — никаких)
--discord-mod vencordnone, vencord, betterdiscord, vesktop
--keep-niri-configне заменять ваш config.kdl, только дописать include
--no-greeterне ставить greeter
--branch <ветка>другая ветка репозитория
вручную 
❯ sudo pacman -S --needed niri quickshell xwayland-satellite kitty git networkmanager pipewire \
    pipewire-pulse wireplumber upower pacman-contrib libnotify polkit-gnome ttf-terminus-nerd paru \
    qt6ct adw-gtk-theme xdg-desktop-portal-gnome
❯ git clone https://github.com/nopoxxx/nopox-shell ~/.config/quickshell

Затем подключите shell к niri — см. extras/niri.kdl.

~/docs/bar/

Панель

Строка shell-приглашения из модулей. Модули расставляются по зонам left / center / right в Mod+S → bar/: ←→ — зона, Shift+↑↓ — порядок. Там же положение, высота, floating-стиль, автоскрытие, разделитель и вид prompt.

модульчто показывает · клики

workspaces~/ws/{1,[2]} — столы этого монитора; клик — перейти
jobs[N] окон на активном столе
command❯ app # title активного окна с эффектом набора; ❯ красный, если окно просит внимания
mediaплеер (MPRIS): клик — пауза, правый — следующий, средний — предыдущий

Трей показывает значки известных программ — Discord, Steam, Telegram, VPN-клиенты, торренты, облака и др.; незнакомые — первой буквой. Вернуть названия: bar/ → трей → names.

~/docs/menu

Меню

Mod+D — меню действий в духе omarchy с нечётким поиском, Mod+Space — сразу программы. Разделы ведут себя как каталоги: ↵ или → — войти, Esc или ← — на уровень выше.

~/
❯ █ ▌ apps/ запуск программ (Mod+Space) wallpaper обои; Tab — wallhaven setup все настройки, мониторы, сеть, звук packages/ установить, удалить, обновить system/ питание и сессия about о системе: fastfetch
  • packages/ — install (репозитории pacman), aur (поиск через paru), remove, update (paru -Syu);
  • system/ — lock, suspend, logout, reboot, poweroff;
  • всё настраиваемое — не в меню, а в окне настроек (setup).
~/docs/settings/

Настройки

Mod+S — окно в стиле menuconfig. Изменения применяются сразу, руками ничего править не нужно. / — поиск по всем настройкам, Tab — разделы, ←→ — значение, r — вернуть по умолчанию. Изменённые значения помечены *.

look/акцент, размер шрифта, темы Qt и GTK, обои, высота меню
windows/отступы, колонки, рамка фокуса, обводка, тени, скругление, прозрачность неактивных, анимации
input/клавиатура и раскладки, бинды, мышь и тачпад, курсор

lock/блокировка по бездействию, эхо пароля, часы, обои, предпросмотр
system/мониторы, сеть, звук, приложения, конфиги, обновления shell

Окна, открытые из настроек (мониторы, бинды, обои), по Esc возвращают в них.

~/docs/settings/monitors

Мониторы

system/ → мониторы: карта расположения, режим и частота, масштаб, поворот, расположение относительно другого монитора (справа от DP-1 и т.п.), VRR и основной монитор.

Любое изменение ждёт подтверждения y 15 секунд — иначе (или n / Esc) всё возвращается как было. Выключить последний работающий монитор нельзя.

~/docs/settings/binds

Бинды

input/ → бинды: все сочетания niri и nopox с поиском — изменить, добавить, отключить, вернуть. Сочетание можно нажать или ввести текстом; перед применением конфиг проверяется niri validate, и если не прошёл — изменение откатывается.

Бинды собираются из трёх слоёв, следующий перекрывает предыдущий:

слойфайлкто пишет
1. nopox~/.config/niri/nopox/binds.kdlshell, из настроек (терминал, браузер…)
2. ваши~/.config/niri/config.kdlвы, руками
3. из окна биндов~/.config/niri/nopox/keys.kdlshell, из окна биндов

Файлы в ~/.config/niri/nopox/ перезаписываются при каждом запуске shell — ручные правки там пропадут. Свои бинды задавайте в окне биндов или в своём config.kdl.

~/docs/settings/wallpapers

Обои

Mod+Shift+W: сетка превью локальной коллекции ~/Pictures/Wallpapers/, Tab — поиск на wallhaven.cc с бесконечной прокруткой; выбранное скачивается в коллекцию. Режимы заполнения fill / fit / stretch, смена — плавная.

~/docs/settings/apps

Приложения по умолчанию

system/ → приложения:

  • терминал — для Mod+Return и окон, которые открывает shell (обновления, nmtui…);
  • файловый менеджер — для Mod+E;
  • оболочка — zsh / fish / bash: откроется терминал с chsh (спросит пароль), действует с нового входа; нет пакета — поставит;
  • браузер — станет браузером по умолчанию и откроется по Mod+Shift+B; нет пакета — поставит через paru.

Оболочка и браузер берутся из системы: если отменить chsh, настройка сама вернётся к тому, что стоит на самом деле.

~/docs/themes

Темы приложений

look/ → темы Qt и GTK: GTK- и Qt-приложения в той же палитре Gruvbox, с тем же акцентом и шрифтом, что и shell, и иконками Gruvbox Plus — через adw-gtk3 / libadwaita и qt6ct. Firefox и Chromium берут тёмную схему через портал.

Уже открытые окна подхватывают изменения после перезапуска приложения; новые — сразу. Свои стили GTK пишите в gtk.css после строки @import "nopox.css";.

~/docs/lock/

Блокировка и greeter

Блокировка (Super+Alt+L, system/ → lock, после бездействия) и greeter для greetd — один и тот же экран в духе getty. Блокировка проверяет пароль через PAM, greeter — через greetd.

Arch Linux 6.x (tty1) nopox-os login: nopox Password: █

В greeter сначала вводится имя (подставлено последнее), Tab — сессия, F11 / F12 — перезагрузка / выключение.

❯ sudo ./extras/install-greeter.sh   # shell → /usr/share/nopox-shell, niri для greeter, greetd
❯ sudo systemctl restart greetd

Greeter работает под пользователем greeter и не видит вашу домашнюю папку — поэтому сессия копирует настройки и обои в /var/lib/nopox-greeter/<user>/, и greeter выглядит как shell последнего вошедшего. После обновления shell greeter переустанавливается отдельно: system/ → обновить greeter.

~/docs/notify/

Уведомления

Shell — сам демон уведомлений. Уведомление — запись лога в рамке, уровень виден по цвету: INFO — акцент, ERROR (критичные) — красный, DEBUG (неважные) — серый. Клик — действие, правый клик — закрыть, наведение ставит таймер на паузу.

┌─[ 21:58 INFO Steam ]────────────────┐ │ friend │ │ Ready to play? │ └─────────────────────────────────────┘ ┌─[ 21:59 ERROR nopox-shell ]─────────┐ │ Настройки не прочитаны │ └─────────────────────────────────────┘

Клик по log на панели — история (до 100), правый клик — «не беспокоить» (проходят только критичные). Положение, время показа и максимум на экране — в notify/.

Steam

Steam рисует свои уведомления отдельным окном, и в niri оно оказывается посреди экрана. Плагин Millennium nopox-notify забирает их у Steam до показа и отправляет как обычные уведомления; свои всплывающие окна Steam больше не показывает.

❯ git clone https://github.com/nopoxxx/nopox-notify && cd nopox-notify
❯ bun install && bun run build   # соберёт и положит в ~/.local/share/millennium/plugins/

Затем включите nopox notify в Steam → Millennium → Plugins и перезапустите Steam.

~/docs/update

Обновления

Shell, установленный через git clone, сам раз в несколько часов делает git fetch. Когда вышли новые коммиты, на панели появляется nopox ↑N: клик — список изменений и [обновить] (git pull --ff-only и перезапуск shell). Частота и уведомление — в system/.

Обновления системы — модуль upd или packages/ → update в меню (paru -Syu).

~/docs/ipc

IPC

Всё, что открывается клавишами, можно вызвать командой — для своих биндов и скриптов:

❯ qs ipc call launcher toggle     # меню; launcher apps — сразу программы
❯ qs ipc call settings toggle     # настройки; settings open <раздел> — look, input, system…
❯ qs ipc call wallpaper picker    # обои; wallpaper set <путь>, wallpaper fill <fill|fit|stretch>
❯ qs ipc call displays toggle     # мониторы
❯ qs ipc call binds toggle        # бинды
❯ qs ipc call lock lock           # блокировка; lock preview — предпросмотр без пароля
❯ qs ipc call notify dnd          # «не беспокоить»; notify clear — очистить историю
~/docs/faq

Вопросы

пропали бинды, которые я вписал в nopox/*.kdl

Эти файлы генерирует shell и перезаписывает при каждом запуске. Задавайте бинды в окне биндов (сохраняются в settings.json) или в своём ~/.config/niri/config.kdl.

пришло «Настройки не прочитаны»

settings.json повреждён. Чтобы не затереть его, shell работает на умолчаниях и ничего не сохраняет. Исправьте JSON (или удалите файл — настройки сбросятся) и перезапустите shell: system/ → перезапустить shell.

как сбросить всё по умолчанию

Удалите ~/.config/nopox/settings.json и перезапустите shell. Отдельное значение — r на нём в настройках.

в трее у программы буква вместо значка

Программы нет в таблице значков. Её можно добавить в TRAY_ICONS в services/settings.js (пришлите PR) или переключить трей на названия: bar/ → трей → names.

как перезапустить shell

❯ pkill -x qs; niri msg action spawn -- qs

Или system/ → перезапустить shell в настройках.

хочу поправить код

Shell — обычный QML и JS в ~/.config/quickshell/. Карта проекта, соглашения и подводные камни — в AGENTS.md.
